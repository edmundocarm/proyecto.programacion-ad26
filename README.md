# Proyecto: menu digital

Contexto: 
La idea del proyecto es crear un menú digital, donde se desplieguen los platillos y su costo así como una breve descripción de este mismo, y que se puedan seleccionar la cantidad. El resultado de esto sería el precio total con propina según lo que considere el usuario y aproximación de tiempo de espera basándose en el platillo que más tarde del pedido para que todo llegue al mismo tiempo. Este proyecto está inspirado en el modelo de La casa de Toño en CDMX donde el usuario selecciona la cantidad de comida, tiene como objetivo reducir el tiempo de espera en lo que el cliente pide de comer ya que al ser un programa sera mucho más facil y rapido ponerse de acuerdo con lo que se quiere pedir.
